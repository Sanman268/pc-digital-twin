# Sensor Placement

Document the exact mounting position of the Thunderboard Sense 2 inside the
PC case here. Measured temperature, light, and vibration values are
meaningless without this context.

## Mount location

- **Position:** _e.g. front-panel intake, 5 cm above the floor of the case_
- **Orientation:** _e.g. board flat, USB connector facing the front panel_
- **Attachment:** _e.g. 3M VHB tape on the chassis_

## RSSI notes

Metal cases attenuate BLE. Record measured RSSI in different positions; if
RSSI < −80 dBm, relocate the board or use a USB extension to move the host
adapter closer.
